### The Odin Project > JavaScript Course > Project: Recursion

Educational project from [The Odin Project's](https://www.theodinproject.com/) Fullstack JavaScript path.

This repository contains solutions for the assignment about writing recursive functions to:
- Return a given amount of Fibonacci numbers
- Sort an array using the merge sort algorithm
